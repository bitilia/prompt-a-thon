# prompt-a-thon wiki

prompt-a-thon is a self-hosted web app for running one competition: public pages, email sign-in, tasks, file submissions, judging, certificates, and an admin panel.

The project site is [prompt-a-thon.bitilia.com](https://prompt-a-thon.bitilia.com).

This folder is the documentation for the software in this repository. It describes what the code does, including limits and behaviour that are easy to miss.
