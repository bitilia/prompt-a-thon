# How it was made

[Wiki home](README.md) · [prompt-a-thon.bitilia.com](https://prompt-a-thon.bitilia.com)

The only model used to make this software was Claude Opus 4.6.

The result is the application in this repository: a Flask competition site with email one-time codes, optional Microsoft sign-in, file submission, judging, certificates, and an admin panel. Sample tasks, the mark scheme, and the academy modules ship with the source so a new install has something to edit. They are starter content.

The public project page is [prompt-a-thon.bitilia.com](https://prompt-a-thon.bitilia.com). The running app does not depend on that site.
